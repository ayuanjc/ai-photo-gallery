## 五、已知限制（如实声明）

1. **「搜 zzzz 出空态」验收项与线上行为冲突**：实测线上 `/api/search` 对 `zzzz` 返回 24 条结果（score 0.2536–0.2688），后端无相似度阈值过滤。前端空态逻辑已完整实现（后端真返 0 条即触发，mock 查「空空如也」可验证），但线上任意词几乎必有结果。若演示需要空态，需后端加 score 阈值（本次任务约定后端零改动，故未处理）。
2. **线上缓存已预热**：实测「海边日落」首次请求即 `text_cached=true`（后端缓存非冷启动）。演示「第二次才命中缓存」的说法不成立，页面会如实展示首次即命中。
3. **视觉与交互未做真机浏览器回归**：本环境无渲染截图能力，12 条自测中标注【浏览器终验】的 4 项（URL 同步、键盘、演示模式、移动端布局）基于代码走查与静态审查通过；建议在 Chrome/Edge/iOS Safari 16+ 各打开一次确认，本地可先跑 `python _mock_server.py` 于 http://127.0.0.1:8899 预验。
4. **mock 假图与线上真图差异**：本地 mock 缩略图为 SVG 渐变占位（321×480 固定比例），线上为真实 webp；布局逻辑相同（img 显式 width/height，加载失败渐变占位）。
5. **场景中文映射为前端内置**：38 个场景 key 与线上 `/api/scenes` 对齐；若后端未来新增场景，前端显示英文 key 原文（不会报错）。
