# 任务 1：场景分析缓存

改 app/scene/analyzer.py：

- 从进程内 LRU 改为 get_cache()

- key: {prefix}scene:{asset_id}

- 值：SceneTags 的 JSON

- TTL: SCENE_CACHE_TTL_SECONDS，默认 86400

- 缓存异常时降级为直接分析，不报错



Settings 末尾追加：

- SCENE_CACHE_TTL_SECONDS: int = 86400



# 任务 2：搜索结果缓存

改 app/services/search_service.py：

- key: {prefix}search:{sha256(query + filters + page + size)}

- 值：SearchResponse 的 JSON

- TTL: SEARCH_CACHE_TTL_SECONDS，默认 300

- 命中直接返回，不调 Immich

- SearchResponse 新增 cached: bool = False

- 降级模式（degraded=true）的结果不写缓存



Settings 末尾追加：

- SEARCH_CACHE_TTL_SECONDS: int = 300



# 任务 3：测试

- 场景分析命中缓存不重复分析

- 搜索命中缓存不调 Immich，cached=true

- 缓存后端异常时降级，接口正常

- 不同参数不串缓存

- 现有测试全绿
