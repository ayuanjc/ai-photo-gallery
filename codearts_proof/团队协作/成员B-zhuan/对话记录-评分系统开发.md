### 项目定位

**AI 图像语义搜索微服务** — 基于 FastAPI 构建的后端微服务，对接 Immich 自托管图库与华为云 AI 能力。

### 功能模块详解

#### 1. 语义搜索引擎（核心）
- 端点：`POST /api/v1/search`
- 9步流水线：缓存查询 → 时间语义解析 → 否定语义解析 → 视觉增强 → 以图搜图 → Immich搜索 → 场景标签附加 → 二次排序 → 去重+可解释性 → 写缓存
- 核心算法：`Final = α·2^(-Age/HalfLife) + β·Similarity`（α=0.3, β=0.7, 半衰期365天）

#### 2. 复合条件搜索
- 端点：`POST /api/v1/search/multi-condition`
- 贝叶斯降级加权评分（person=0.5, location=0.3, query=0.2）

#### 3. 语义增强组件（6个子能力）
- 时间解析、否定解析、以图搜图、搜索建议、反馈闭环、可解释性

#### 4. 人脸分类（华为云 FRS）
- 端点：`POST /api/v1/faces/classify`
- 高斯核概率 `P=exp(-((1-Sim)²)/(2σ²))` + 并查集软聚类

#### 5. AI 分析（同人/相似图）
- 端点：`POST /api/v1/ai/analyze`
- Provider工厂模式：immich / huawei

#### 6. 场景分析
- 端点：`GET /api/v1/scenes`
- 词典匹配 + HTTP推理 + 时间衰减LFU缓存

#### 7. 统计大屏
- 端点：`GET /api/v1/stats/map`、`/stats/exif`、`/stats/gear`

#### 8. 批量导入
- 端点：`POST /api/v1/import/batch`
- EXIF提取 + Immich上传，目录白名单安全

#### 9. 水印管理
- 端点：`POST /api/v1/watermark/apply`
- ProcessPoolExecutor子进程渲染

#### 10. 管理后台（前端）
- 访问：`GET /admin`（单文件SPA，1858行原生HTML/CSS/JS）
- 5个页面：总览、功能开关、系统状态、配置管理、统计大屏

#### 11. 基础设施
- 统一异常、缓存（Memory/Redis双后端）、限流（令牌桶）、安全（SSRF+路径穿越防护）

### PR 描述模板

#### 变更概述

本 PR 为照片库新增 **照片评分系统**，支持对 Immich 资产进行 1-5 星评分，并在语义搜索结果中附加评分数据与按评分阈值过滤。评分数据通过 SQLAlchemy 异步引擎持久化到 SQLite 数据库，使用 UPSERT（INSERT ON CONFLICT DO UPDATE）原子语义保证创建与更新的线程安全。

#### 新增功能列表

| 功能 | 端点 | 说明 |
|------|------|------|
| 创建评分 | `POST /api/v1/ratings` | UPSERT 语义，已存在则更新 |
| 更新评分 | `PUT /api/v1/ratings/{asset_id}` | 不存在则创建 |
| 获取单条 | `GET /api/v1/ratings/{asset_id}` | 不存在返回 404 |
| 删除评分 | `DELETE /api/v1/ratings/{asset_id}` | 返回 deleted 状态 |
| 批量获取 | `POST /api/v1/ratings/batch` | 避免 N+1 查询 |
| 评分统计 | `GET /api/v1/ratings/stats` | 总数/均分/分布/Top10 |
| 搜索附加评分 | `POST /api/v1/search/smart` | 结果自动附加 rating 字段 |
| 按评分过滤 | `POST /api/v1/search/smart` | 传 `min_rating` 参数过滤 |

#### 约束遵循情况

- ✅ **不破坏现有功能**：搜索路由仅在获取 SearchResponse 后做后处理附加评分

- ✅ **UPSERT 语义**：使用 SQLite `INSERT ON CONFLICT DO UPDATE` 原子操作
- ✅ **唯一约束**：`(asset_id, user_id)` 组合唯一，未指定 user_id 时默认 `"default"`
- ✅ **优质成片筛选策略**：`get_asset_ids_by_min_rating` 先在本地筛选 asset_id
