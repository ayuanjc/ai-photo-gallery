## 2. AGPL 合规说明

1. **未分发、未修改 Immich 源码**：本项目仅以独立客户端身份调用 Immich 的 HTTP API（相册、标签、人物、资产接口），通过网络交互，不构成 AGPL 意义上的「分发」或「衍生作品」。
2. **本仓库不含任何 Immich 代码**：可自行检索仓库验证，无 Immich 源码复制。
3. **官方插件机制集成**：与 Immich 的深度联动（写回、工作流）走 Immich 官方插件/扩展机制，遵循其设计边界。
4. 演示站（487 张样例）完全不依赖 Immich，可独立复现算法链路。

## 3. 我们的原创增量

以下均为本项目自研，非 Immich 或任何第三方组件自带能力：

1. **中文→英文短语改写**（`app/scene/query_translate.py`）：把「海边日落」这类中文口语改写为 CLIP 词表友好的英文短语（`a photo of the sunset at the beach`），解决 CLIP 中文查询分数整体偏低、语义失焦的问题；最长优先贪心匹配 + 组合模板。
2. **场景标签体系**（38 个场景 key + 中文映射 + 阈值控制）：为检索结果提供可解释的归类维度，支持按场景聚合统计。
3. **连拍去重信号**：相似度聚簇内的连拍识别，避免同一瞬间照片刷屏结果页。
4. **写回审计与回滚**（`app/services/immich_writeback.py`、`writeback_manager.py`）：对写回 Immich 的每一次标签/描述/相册变更记录审计日志，支持一键回滚；写回闸门规则（仅 source=analyzed 可写回、兜底值禁写回）。
5. **WASM 工作流插件**（`app/api/routes/plugin.py` 挂载）：以 Immich 工作流插件形态在入库链路上触发本服务分析。
6. **双源配置**（`.env` + 管理台）：环境变量与管理页面双通道配置，管理台可热改并探针验证。
7. **增量水位同步**：按资产更新水位增量拉取 Immich 变更，避免全量重扫（2.9 万张照片场景下的工程必要性）。
8. **管理台**（`app/static/admin.html`）：设置、统计大屏（地图/EXIF/器材）、搜索调试一体的运维前端。
