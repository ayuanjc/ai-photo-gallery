# 01 · 环境依赖与一键安装

> 目标：评委在一台干净的服务器上，按本文档 + `install.sh` 复现「云影图鉴」在线演示站（最小可运行路径），或进一步接入 Immich 跑完整版。

## 1. 环境要求

| 项 | 要求 | 说明 |
|---|---|---|
| 操作系统 | Debian 12 / Ubuntu 22.04 | 已在腾讯云广州节点 Debian（2 核 4G 5M）实测 |
| Python | ≥ 3.11 | 自带 `python3` 即可，装 venv 用 |
| 系统包 | `python3-venv`、`nginx`、`curl` | install.sh 自动安装，已装则跳过（幂等） |
| 磁盘 | ≥ 1 GB | CLIP 文本塔 `model.data` 406 MB 占绝大多数 |
| 内存 | ≥ 2 GB（推荐 4 G） | uvicorn 常驻 RSS 实测 348 MB；systemd 限制 MemoryMax=1600M |
| 完整版附加 | `redis-server`、Docker（运行 Immich v3） | 仅「完整版」路径需要，最小路径不需要 |

## 2. 两条运行路径

| 路径 | 依赖 Immich | 说明 |
|---|---|---|
| **最小可运行**（推荐评委先跑这条） | 否 | `demo/serve_demo.py` + 487 张样例向量 + CLIP 文本塔 ONNX，本机 CPU 推理，nginx 静态页。对应线上 http://106.52.116.164 |
| **完整版** | 是 | `app/` 全栈：51 个端点、1085 条测试，接 Immich v3（相册/标签/人物写回、WASM 工作流插件）+ Redis |

## 3. ONNX 模型文件（唯一不随仓库分发的大件）

CLIP ViT-B-32 文本塔共 3 个文件，放在 `$APP_DIR/models/`（install.sh 会检查）：

| 文件 | 大小 | 来源 |
|---|---|---|
| `model.onnx` + `model.data` | 406 MB | 从 `immich_machine_learning` 容器导出（见下），与本地全量版同一语义空间（cos=1.000000 实测） |
| `tokenizer.json` | ~2 MB | 同上（BOS 49406 / EOS 49407，上下文 77） |

获取方式（服务器上执行，需已有 Immich 环境）：

```bash
# 适用：Debian 12 / Ubuntu 22.04（装有 Immich 的机器）
docker cp immich_machine_learning:/cache/clip/ViT-B-32__openai/textual/cpu/x86_64/batch1/model.onnx  $APP_DIR/models/
docker cp immich_machine_learning:/cache/clip/ViT-B-32__openai/textual/cpu/x86_64/batch1/model.data  $APP_DIR/models/
docker cp immich_machine_learning:/cache/clip/ViT-B-32__openai/textual/cpu/x86_64/batch1/tokenizer.json $APP_DIR/models/
```

> TODO：若无 Immich 环境，可向团队索取模型包（网盘链接待补）；或参考 Immich 官方 `immich-machine-learning` 镜像自行拉起容器后导出。

**版本红线**：`onnxruntime` 必须为 **1.31.0**（与容器 manifest 的 1.30.x 对齐）。1.20 及以下读取 prepacked 外部数据会报 `Deserialize tensor failed`（demo/requirements.txt 内有注释为证）。

## 4. install.sh 全文

```bash
#!/usr/bin/env bash
# 云影图鉴 · 一键安装（最小可运行路径）
# 适用：Debian 12 / Ubuntu 22.04，root 或 sudo 执行
# 特性：每步幂等（重复执行无副作用）；任一步失败自动回滚 systemd/nginx 配置
# 用法：在仓库检出目录内执行  bash readme/install.sh
set -euo pipefail

APP_DIR=${APP_DIR:-/opt/yunying}
SVC=${SVC:-yunying-demo}
TS=$(date +%Y%m%d%H%M%S)
STEP="init"

rollback() {
  trap - EXIT  # 防止递归触发
  echo "!! 步骤【$STEP】失败，回滚已变更的系统配置"
  for f in "/etc/systemd/system/${SVC}.service" /etc/nginx/sites-available/yunying; do
    if [ -f "$f.bak.$TS" ]; then mv -f "$f.bak.$TS" "$f"; echo "已还原 $f"; fi
  done
  systemctl daemon-reload 2>/dev/null || true
  nginx -t >/dev/null 2>&1 && systemctl reload nginx || true
  echo "回滚完成。请根据上方报错排查后重试（脚本可重复执行）。"
  exit 1
}
# 用 EXIT 而非 ERR：显式 exit 1 与 set -e 的失败退出都会触发 EXIT，
# ERR trap 捕获不到 exit 1（bash 语义），会导致最需回滚的路径静默失效
trap rollback EXIT
step() { STEP="$1"; echo "== $1 =="; }

step "1/7 系统包（幂等）"
NEED=()
dpkg -s python3-venv  >/dev/null 2>&1 || NEED+=(python3-venv)
dpkg -s nginx         >/dev/null 2>&1 || NEED+=(nginx)
dpkg -s curl          >/dev/null 2>&1 || NEED+=(curl)
if [ ${#NEED[@]} -gt 0 ]; then apt-get update -qq && apt-get install -y -qq "${NEED[@]}"; else echo "已安装，跳过"; fi

step "2/7 Python 版本检查"
python3 -c 'import sys; sys.exit(0 if sys.version_info >= (3,11) else 1)' \
  || { echo "需要 Python >= 3.11（当前 $(python3 -V)）"; exit 1; }

step "3/7 目录与代码"
mkdir -p "$APP_DIR/app" "$APP_DIR/web" "$APP_DIR/data/thumbs" "$APP_DIR/models" "$APP_DIR/venv"
cp -f demo/serve_demo.py demo/query_translate.py demo/requirements.txt "$APP_DIR/app/"
cp -f demo/web/index.html "$APP_DIR/web/"
if [ -f data/demo/embeddings.npy ]; then
  cp -f data/demo/embeddings.npy data/demo/meta.json "$APP_DIR/data/"
  cp -f data/demo/thumbs/*.webp "$APP_DIR/data/thumbs/" 2>/dev/null || true
else
  echo "提示：样例向量 data/demo/embeddings.npy 未找到，请先从仓库 data/demo/ 上传"
fi

step "4/7 venv 与依赖（幂等）"
if [ ! -x "$APP_DIR/venv/bin/pip" ]; then python3 -m venv "$APP_DIR/venv"; fi
"$APP_DIR/venv/bin/pip" install -q --upgrade pip
"$APP_DIR/venv/bin/pip" install -q -r "$APP_DIR/app/requirements.txt"
"$APP_DIR/venv/bin/python" -c "import onnxruntime,numpy,tokenizers,fastapi; print('deps ok, ort', onnxruntime.__version__)"
"$APP_DIR/venv/bin/python" - <<'PY'
import onnxruntime as o
major, minor = o.__version__.split(".")[:2]
if int(major) < 1 or (int(major) == 1 and int(minor) < 31):
    raise SystemExit("onnxruntime 必须 >= 1.31.0（1.20 读不了 prepacked 外部数据）")
print("ort 版本检查通过")
PY

step "5/7 模型文件检查"
for f in model.onnx model.data tokenizer.json; do
  [ -s "$APP_DIR/models/$f" ] || { echo "缺少 $APP_DIR/models/$f —— 请按 readme/01 第 3 节从 immich_machine_learning 容器导出"; exit 1; }
done
echo "模型三件套就绪：$(du -sh "$APP_DIR/models" | cut -f1)"

step "6/7 systemd（幂等 + 备份回滚）"
cat > "$APP_DIR/yunying-demo.service" <<UNIT
[Unit]
Description=YunYing semantic search demo
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=$APP_DIR/app
ExecStart=$APP_DIR/venv/bin/uvicorn serve_demo:app --host 127.0.0.1 --port 8100 --workers 1
Restart=always
RestartSec=3
Environment=DEMO_BASE=$APP_DIR
Environment=DEMO_CLIP_DIR=$APP_DIR/models

# 内存兜底：2C4G 上把上限压在 1.6G，超了只杀自己
MemoryMax=1600M

# 沙箱加固：公网 Web 服务不以 root 运行，最小权限 + 文件系统只读
NoNewPrivileges=true
ProtectSystem=strict
ProtectHome=true
PrivateTmp=true
ProtectKernelTunables=true
ProtectControlGroups=true
RestrictSUIDSGID=true
ReadOnlyPaths=$APP_DIR

[Install]
WantedBy=multi-user.target
UNIT
if [ -f "/etc/systemd/system/${SVC}.service" ]; then cp "/etc/systemd/system/${SVC}.service" "/etc/systemd/system/${SVC}.service.bak.$TS"; fi
cp -f "$APP_DIR/yunying-demo.service" "/etc/systemd/system/${SVC}.service"
systemctl daemon-reload && systemctl enable "${SVC}"
systemctl restart "${SVC}"
# 等待服务就绪（Restart=always 下 is-active 可能落在 activating 窗口）
ok=""
for i in 1 2 3 4 5; do
  if systemctl is-active --quiet "${SVC}"; then ok=1; break; fi
  sleep 2
done
[ -n "$ok" ] || { journalctl -u "${SVC}" -n 30 --no-pager; exit 1; }

step "7/7 nginx（幂等 + 备份回滚）"
NG=/etc/nginx/sites-available/yunying
cat > /tmp/yunying.nginx <<NGINX
server {
    listen 80 default_server;
    server_tokens off;
    root $APP_DIR/web;
    index index.html;

    add_header X-Content-Type-Options nosniff always;
    add_header X-Frame-Options DENY always;
    add_header Referrer-Policy no-referrer always;

    location /api/ {
        proxy_pass http://127.0.0.1:8100/api/;
        proxy_set_header Host \$host;
    }
    location /thumbs/ {
        alias $APP_DIR/data/thumbs/;
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
    gzip on;
    gzip_types text/html application/json image/svg+xml;
}
NGINX
[ -f "$NG" ] && cp "$NG" "$NG.bak.$TS"
cp -f /tmp/yunying.nginx "$NG"
ln -sf "$NG" /etc/nginx/sites-enabled/yunying
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx

step "自检"
curl -fsS --max-time 10 http://127.0.0.1/api/health && echo

trap - EXIT  # 全部成功，解除回滚
IP=$(hostname -I | awk '{print $1}')
echo "安装完成 → http://$IP"
echo "（云主机/NAT 环境请改用公网 IP 访问；安全组/防火墙需放行 80 端口）"
```

## 6. 完整版（接 Immich）附加步骤

```bash
# 适用：Debian 12 / Ubuntu 22.04
apt-get install -y redis-server && systemctl enable --now redis-server
# Immich v3：按官方文档 docker compose 部署，或在管理台配置已有实例
cd $APP_DIR && python3 -m venv venv-full && venv-full/bin/pip install -r requirements.txt
cp .env.example .env   # 填 IMMICH_BASE_URL / IMMICH_API_KEY 等
venv-full/bin/python -m pytest tests/ -q   # 1085 条测试应全绿（退出码 0）
venv-full/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
```
