## P5 功能架构总图

- 副标题：从一句中文到一张照片
- 要点（一张图讲完）：
  ```
  中文查询 → 短语改写 → CLIP 文本塔(ONNX) → 向量检索(487/29,712) → 动态排序(α·时间+β·相似度) → 结果+写回 Immich
  ```
  1. 全链路本机 CPU 推理，无外部 AI API
  2. 查询缓存命中 0.7ms，未命中 70ms
  3. Redis 两级缓存 + nginx 静态加速
- 建议图表：横向六节点流程图（主色箭头串联，节点下标实测耗时）
- 口播 30 秒：「架构一条链：中文查询先改写成英文短语，过 CLIP 文本塔得到语义向量，与图像向量做余弦检索，再按时间与相似度动态加权排序，最后还能把结果写回相册。全链路 CPU 推理，命中缓存不到 1 毫秒。」
