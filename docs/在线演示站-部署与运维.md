# 云影图鉴 · 在线演示站（106.52.116.164）

> 一句话：把"中文一句话 → 语义检索照片"这条链路原样搬到公网，用 487 张精选样例 + 容器里导出的 CLIP 文本塔 ONNX 在本机做推理；不依赖 Immich，不依赖任何外部 API，不打假分。

## 1. 为什么是"形态 B"

| 方案 | 可行性 | 结论 |
|---|---|---|
| 整栈上云（Immich + ML + Postgres + 本项目） | 常驻 2.5 GiB / 2.9 万张索引重建在 2 核上不可行 | 否 |
| **宣传站 + 样例检索 demo** | 静态页 + 500 行 FastAPI + 400MB 文本塔 | **采用** |
| 只放 PPT/录屏 | 评审无法自己点 | 否 |

完整系统（29,712 张照片、1,081 段视频、Immich 原生插件与写回）留在本地全量环境演示。

## 2. 架构

```
浏览器 ──HTTP:80──> nginx 1.22
                     ├── /            → /opt/yunying/web/index.html（8.4 KB gzip）
                     ├── /thumbs/*    → /opt/yunying/data/thumbs/*.webp（487 张，7.3 MB，30 天强缓存）
                     └── /api/*       → 127.0.0.1:8100  uvicorn (1 worker)
                                          └── serve_demo.py
                                              ├── onnxruntime：CLIP 文本塔 model.onnx + model.data(406 MB)
                                              ├── tokenizers：tokenizer.json（BOS 49406 / EOS 49407，77 上下文）
                                              ├── embeddings.npy：(487, 512) float32，已 L2 归一化
                                              └── query_translate.py：中文 → CLIP 词表短语
```

关键点：**文本塔是从 immich_machine_learning 容器里直接导出的同一份 ONNX**（`/cache/clip/ViT-B-32__openai/textual/cpu/x86_64/batch1/`），与本机 Immich ML 的 `/predict textual` 实测 **cos = 1.000000**，所以云端打出的分数和本地全量版是同一套语义空间。

## 4. 素材构建（可重跑）

```bash
python tools/build_demo_assets2.py --per-seed 24 --extra 60
```

- 种子查询定向取图：不再随机抽样。随机抽样抽到的 200 张里**没有任何一张海边日落**，导致"海边日落"top1 余弦只有 0.1994 且视觉完全无关 —— 这是演示翻车的直接原因，已修。
- 坏图过滤：灰度标准差 < 8 判纯色、相邻像素差均值 > 32 判噪声（实测拦下 1 张噪声图、1 张纯色图）。
- 压缩：最长边 480、WebP quality 76，单张约 15 KB，全库 7.3 MB。
- 结果：487 张，18 个主题各 24 张 + 60 张背景，实测量级覆盖到"火锅 / 蓝色的车 / 雪山 / 烟花 / 街边小吃"等中文口语。

## 7. 已知限制（别在评审现场被问住）

1. **只有 487 张样例**，不是全库。页面已明写"全量版在本地：29,712 张照片 + Immich 原生插件"，不要现场谎称全量。
2. **单进程串行**：2 核 + 1 worker，10 个并发不同查询会排队到 0.7 s。演示是单用户场景，够用；真要多并发得上 4 核或加 workers（每个 worker 多 350 MB）。
3. **无鉴权、无 HTTPS**：广州节点绑域名需 ICP 备案 2–3 周。当前用 IP + HTTP，表单页无敏感数据，可接受；要 HTTPS 就先备案再签证书。
4. **文本塔是 fp32 406 MB**：换成 int8 量化可压到 ~100 MB、推理更快，但要重跑 parity 校验（与 Immich 语义空间必须一致，否则分数口径就对不上本地全量版）。
5. **5 Mbps 峰值带宽**：487 张全量 7.3 MB，首屏只拉 8 张 ≈ 120 KB，不会打满；别做"一次加载全部缩略图"。
