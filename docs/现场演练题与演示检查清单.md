# 现场改需求演练（4 题）+ 演示前 10 分钟检查清单

> 目的：决赛现场 5 分钟内用码道改代码的实战演练。每题：评委说法 → 改哪里 → 码道提示词 → 验证 → 回滚。
> 约束：改动 ≤30 行、3 分钟内跑通 pytest、回滚一条命令。

## 题 1 「能不能加个按拍摄年份筛选？」

- **评委可能的说法**：「想只要 2025 年拍的照片，能按年份筛吗？」
- **改动位置**：
  - `app/models/request.py` → `SearchRequest`（第 42 行起）加 `year` 字段
  - `app/services/search_service.py` → `search()`（第 59 行起）结果过滤
  - 路由 `app/api/routes/search.py` 无需改（Pydantic 自动透传）
- **码道提示词**：

```text
在 app/models/request.py 的 SearchRequest 增加可选字段：
year: int | None = Field(default=None, ge=1990, le=2100, description="按拍摄年份精确过滤")
在 app/services/search_service.py 的 search() 中，返回结果前若 year 非空，
按 takenAt 的 UTC 年份过滤 results（takenAt 为空视为不匹配）。
总改动不超过 30 行，不改动其他逻辑；在 tests/ 下补 3 条用例：
空 year 不过滤、year 命中过滤、year 无匹配返回空。只跑新增用例。
```

- **验证命令**：
  - `venv/bin/python -m pytest tests/ -k "year" -x -q`（预期 3 passed）
  - `curl -s -X POST http://127.0.0.1:8000/api/v1/search -H "Content-Type: application/json" -d '{"query":"晚会","asset_ids":["x"],"year":2025}'`
- **回滚**：`git checkout -- app/models/request.py app/services/search_service.py tests/`

## 题 2 「分数能不能只显示前 10 张？」

- **评委可能的说法**：「结果太多看不过来，先给我看前 10 张就行。」
- **改动位置**：`demo-web/index.html`（第 480 行附近 `top_k: TOP_K`，改 `TOP_K` 常量定义为 10）
- **码道提示词**：

```text
把 demo-web/index.html 中 TOP_K 常量的值从 24 改为 10，只改这一处，其余全部不动。
```

- **验证命令**：刷新演示页搜索任一词，结果网格恰 10 张；`grep -n "TOP_K = " demo-web/index.html`
- **回滚**：`git checkout -- demo-web/index.html`

## 题 3 「搜出来有张图是错的，能屏蔽它吗？」

- **评委可能的说法**：「这张明显不相关，能不能把它从结果里去掉？」
- **改动位置**：
  - `app/models/request.py` → `SearchRequest` 加 `exclude_ids`
  - `app/services/search_service.py` → `search()` 过滤
- **码道提示词**：

```text
SearchRequest 增加字段：
exclude_ids: list[str] = Field(default_factory=list, max_length=100, description="结果中需要排除的资产 ID")
app/services/search_service.py 的 search() 在排序完成后，剔除资产 ID 命中 exclude_ids 的结果。
改动 ≤30 行；tests/ 补 3 条用例：空列表不过滤、命中剔除、剔除后排序保持。只跑新增用例。
```

- **验证命令**：
  - `venv/bin/python -m pytest tests/ -k "exclude" -x -q`（预期 3 passed）
  - curl 搜索后取一条结果 id，带 `exclude_ids` 重搜确认消失
- **回滚**：`git checkout -- app/models/request.py app/services/search_service.py tests/`

## 题 4 「能不能把结果按相似度做成柱状图？」

- **评委可能的说法**：「分数高低能不能更直观一点，比如柱状图？」
- **改动位置**：`demo-web/index.html`（结果区加「网格/柱状图」切换；柱状图用每条结果的 `score` 渲染横向条，宽度 = score/top1_score × 100%）
- **码道提示词**：

```text
demo-web/index.html 增加「网格 / 柱状图」视图切换（纯 CSS，不加任何外部库）：
柱状图模式：纵向列表，每行 = fileName 前 20 字 + score 三位小数 + 横向条形（宽度=score/最高score*100%），
条形用现有 --accent 色，hover 显示缩略图 title。切换按钮放在状态行右侧，键盘 V 键切换。
总改动 ≤30 行，保持深色主题变量，不动搜索逻辑。
```

- **验证命令**：浏览器打开演示页，搜「海边日落」，点切换/V 键，24 根条形按分数降序；`python -m py_compile` 无关，改的是 html，直接目视 + `grep -c bar chart` 之类核对字面量
- **回滚**：`git checkout -- demo-web/index.html`

### 演练通用纪律

1. 改前必建分支：`git checkout -b live-demo-change`，改完演示成功后立即 `git checkout main && git branch -D live-demo-change`
2. 每题独立做，不叠加；演示现场只做 1 题（评委点哪道做哪道）
3. 码道改完先自己读完 diff 再跑验证，不盲交
