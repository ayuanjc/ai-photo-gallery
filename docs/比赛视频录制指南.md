# 比赛视频录制指南（≤3 分钟）

> 硬上限 3:00，按 **2:50** 设计。超时即不合规，没有商量余地。

---

## 0. 开录前 3 分钟：必须先过这 3 关

### ① 浏览器能不能打开演示站（最容易翻车）

你的机器上有死代理 `HTTP_PROXY=http://127.0.0.1:7891`（端口无监听）。浏览器走它 → 所有外网 http 全挂。

**验证**：地址栏敲 `http://106.52.116.164`，能出页面就过。出不来按顺序试：

1. Windows 设置 → 网络和 Internet → 代理 → **关闭"使用代理服务器"**
2. 打开你的 VPN 客户端连上（代理才活）
3. 都不行就开隧道：`powershell -File tools\monitor-tunnel.ps1 start`，然后访问 `http://127.0.0.1:8123`

⚠️ 隧道方式**不能录**——地址栏会露出 `127.0.0.1`，评委会觉得是本地假站。必须让地址栏显示 `106.52.116.164`。

### ② 演示站预热

开录前先手动跑 3 次查询（海边日落 / 火锅 / 蓝色的车），把 ONNX 模型和 tokenizer 全部载入内存。冷启动第一次查询要 3–5 秒，录进去就废了。预热后稳定 70ms。

### ③ 录一条 10 秒废片试机

确认：声音有没有、字清不清楚、有没有录到第二块屏。废片删掉再正式开录。

## 3. 录制参数

### 用什么录

任选其一，都行：

- **OBS Studio**（推荐）：输出 1920×1080 / 30fps / CQP 20 / 录显示器
- **Windows 自带**：`Win + G` → 录屏（只能录单窗口，够用）
- **PowerPoint** → 插入 → 屏幕录制（最省事，但只能存进 PPT）

OBS 关键设置：
- 视频 → 基础/输出分辨率都设 1920×1080，FPS 30
- 输出 → 录制格式 `mp4`，编码器 `x264`，CRF 20
- 音频 → 麦克风 + 桌面音频都给一点（有键盘声更真实）

### 环境清理（录前 2 分钟做）

- [ ] 关微信 / QQ / 邮件 / 所有弹窗类软件
- [ ] Win → 设置 → 系统 → 专注助手 → **仅闹钟**
- [ ] 浏览器：`Ctrl+Shift+B` 隐藏书签栏，关掉无关标签页（只留演示站 + 监测面板）
- [ ] 浏览器缩放 **125%**（`Ctrl + 加号` 两次），字才看得清
- [ ] 桌面图标全选隐藏（右键桌面 → 查看 → 取消"显示桌面图标"）
- [ ] 任务栏右键 → 自动隐藏
- [ ] 终端字体调到 20pt，背景纯黑，别用花哨主题

## 4. 后期

用你装好的 DaVinci Resolve（或剪映，更快）。

只做 4 件事，别加特效：

1. 按上面分镜裁切拼接
2. 加字幕（硬字幕，别做软字幕，评委会用手机看）
3. 给 1:08–1:30 的测试滚动加速 4×
4. 片头片尾各加一个 0.3 秒黑场

**不要**做的：转场特效、背景音乐压过键盘声、花字动画、每 3 秒切一次镜。评委看的是作品，不是剪辑。

字幕规范：字号 ≥ 32px（1080p 下），黑底白字或白底黑字，带 60% 不透明底框，位置固定在底部安全区。

## 6. 五个翻车点（都真发生过）

| 翻车 | 后果 | 预防 |
|---|---|---|
| 浏览器打不开演示站 | 录到一半崩溃 | 开录前必做第 0 节 |
| 没预热，第一次查询 4 秒 | 视频里一段死等 | 手动跑 3 次再录 |
| 录到第二块屏 / 竖屏 | 画面一半是黑的 | OBS 预览先看，录 10 秒试机 |
| 微信弹窗 | 整段废 | 专注助手 + 退微信 |
| 导出用了 HEVC/H.265 | 评委电脑播不了 | 必须 H.264 |

## 7. 如果今天实在来不及

规则允许 `video/` 放一个 `video_link.txt` 写在线地址，代替本地 mp4。

**但别指望它**：上传要审核、链接会失效、评委可能点不开。本地 mp4 是唯一保险的做法。

真赶不上就这样排：今天先交 PPT + 一个**能看的最低配版本**（只有 S2 检索 50 秒 + S5 数字墙 15 秒，共 65 秒），明后天再交完整版。反正每天能交一次，取最高分。
