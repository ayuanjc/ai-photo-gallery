## 2. 五处硬伤（必须改）

### 硬伤 1 · P13 第 2 条是 TODO —— 交评委的材料不能有 TODO

现状（第 155 行）：`2. TODO：其他华为云服务用量待补（如 ModelArts/OBS 等，以实际账单为准）`

```
2. 华为云生态可延展：模型推理可迁 ModelArts、素材存储可走 OBS、CI 可挂 CodeArts Pipeline；
   接口层已做 endpoint 抽象，本次为控成本在轻量云验证，迁云只换配置不改代码
```
